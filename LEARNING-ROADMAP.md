# OCI Learning Roadmap

## Phase 1 — Foundation and identity (Weeks 1–2)
- [ ] Tenancy, regions, availability domains and compartments.
- [ ] IAM policies, identity domains, groups and dynamic groups.
- [ ] Tags, quotas, budgets and Core Landing Zone.
- [ ] OCI CLI authentication and safe lab hygiene.

**Checkpoint:** Explain compartment hierarchy and OCI policy authorization.

## Phase 2 — Networking and compute (Weeks 3–5)
- [ ] VCNs, subnets, route tables, security lists and NSGs.
- [ ] Gateways, DRG, LPG, FastConnect and VPN concepts.
- [ ] Compute, instance pools, Load Balancer and WAF.
- [ ] Complete a secure application network lab.

**Checkpoint:** Trace packet flow and justify routing and security rules.

## Phase 3 — Storage, databases and containers (Weeks 6–8)
- [ ] Object Storage, Block Volume and File Storage Service.
- [ ] Autonomous Database and another database option.
- [ ] OKE, OCIR, OCI Functions and API Gateway.
- [ ] Complete one portfolio project.

**Checkpoint:** Explain why the selected platform fits the workload.

## Phase 4 — Enterprise operations (Weeks 9–12)
- [ ] Terraform with OCI provider and OCI Resource Manager.
- [ ] OCI DevOps, Monitoring, Logging, Audit and Alarms.
- [ ] Vault, Cloud Guard, Security Zones and Data Safe.
- [ ] Backup, replication, Full Stack Disaster Recovery and FinOps.
- [ ] Present a design with threat model, SLO, RTO/RPO and cost model.

Weekly loop: Read Oracle docs → diagram → deploy minimal sandbox lab → test failure → record cost → clean up → practice architecture interview questions.
