## Architecture practice
1. Identify tenancy and compartment boundaries that apply.
2. Map OCI IAM policies and workload principals.
3. Diagram VCNs, subnetting, routes, gateways and security controls where relevant.
4. Identify availability, backup/restore, monitoring and cost requirements.
5. Complete a sandbox lab and record validation/cleanup evidence.
